## Ghoul Cyber – Theme Studio v1.0.2

**🇬🇧 English** · [🇵🇱 Polski](#-polski)

- **Only Windows on the PC? One click is enough.** **BUILD AND INSTALL** now also installs rEFInd itself when the PC has none: it downloads the official rEFInd 0.14.2 (SHA-256 checked), copies it to the EFI partition, adds a new *rEFInd* boot entry in front of *Windows Boot Manager* (which is never changed) and pauses BitLocker for the next 2 restarts, so Windows does not ask for the recovery key. No Linux and no command line needed.
- **Secure Boot on?** Nothing is installed. Theme Studio pauses BitLocker and offers to restart straight into the BIOS/UEFI settings, where you turn Secure Boot off — then click the button again.
- **Remove rEFInd** (Windows): removes the boot entry and the `EFI\refind` folder this app installed; Windows starts directly again.
- After a big Windows update puts Windows first again, clicking **BUILD AND INSTALL** puts rEFInd back in front.
- Engine updated to [`studio-engine-v1.0.2`](https://github.com/Dismonder/refind-theme-ghoul-cyber/tree/studio-engine-v1.0.2) — step-by-step guide: [Only Windows on your PC?](https://github.com/Dismonder/refind-theme-ghoul-cyber#-only-windows-on-your-pc-step-by-step-guide)

**Download:** `ghoul-cyber-theme-studio-v1.0.2.zip` — Windows: `ThemeStudio.bat` (Python 3), Linux: `./theme-studio.sh` (Python 3 + Tk). Checksums: `sha256sum -c SHA256SUMS.txt`.

🎭 17 of the 18 themes are unofficial, non-commercial fan art — not affiliated with or endorsed by the rights holders.

### 🇵🇱 Polski

- **Masz tylko Windowsa? Wystarczy jedno kliknięcie.** **ZBUDUJ I ZAINSTALUJ** instaluje teraz także sam rEFInd, gdy komputer go nie ma: pobiera oficjalny rEFInd 0.14.2 (sprawdza sumę SHA-256), kopiuje go na partycję EFI, dodaje nowy wpis rozruchowy *rEFInd* przed *Windows Boot Managerem* (ten nigdy nie jest zmieniany) i wstrzymuje BitLockera na 2 najbliższe restarty, żeby Windows nie pytał o klucz odzyskiwania. Bez Linuksa i bez wiersza poleceń.
- **Włączony Secure Boot?** Nic nie jest instalowane. Theme Studio wstrzymuje BitLockera i proponuje restart prosto do ustawień BIOS/UEFI, gdzie wyłączasz Secure Boot — potem klikasz przycisk jeszcze raz.
- **Usuń rEFInd** (Windows): usuwa wpis rozruchowy i folder `EFI\refind` zainstalowane przez aplikację; Windows znów startuje bezpośrednio.
- Gdy duża aktualizacja Windowsa znów ustawi Windowsa na początku, kliknięcie **ZBUDUJ I ZAINSTALUJ** przywraca rEFInd na pierwsze miejsce.
- Silnik zaktualizowany do [`studio-engine-v1.0.2`](https://github.com/Dismonder/refind-theme-ghoul-cyber/tree/studio-engine-v1.0.2) — poradnik krok po kroku: [Masz tylko Windowsa?](https://github.com/Dismonder/refind-theme-ghoul-cyber/blob/main/README.pl.md#-masz-tylko-windowsa-poradnik-krok-po-kroku)

**Pobieranie:** `ghoul-cyber-theme-studio-v1.0.2.zip` — Windows: `ThemeStudio.bat` (Python 3), Linux: `./theme-studio.sh` (Python 3 + Tk). Sumy kontrolne: `sha256sum -c SHA256SUMS.txt`.
