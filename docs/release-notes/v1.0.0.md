## 👁️ Theme Studio v1.0.0 — first release

**🇬🇧 English** · [🇵🇱 Polski](#-polski)

The app for the [Ghoul Cyber rEFInd theme](https://github.com/Dismonder/refind-theme-ghoul-cyber): build your own boot screen in a few minutes.

- **18 themes** with a **live preview** of the final rEFInd screen (17 are 🎭 fan art — see below).
- Every option as a form: resolution, tile sizes, how many system tiles are visible, scroll arrows, HUD texts, tile numbers and their order, tools in the bottom row, timeout, default system, your own menu entries.
- **BUILD** or **BUILD & INSTALL** in one click — Linux (any major distribution; installs rEFInd itself if it is missing) and Windows (UAC).
- Fail-safe: invalid values block building, installs roll back on any error, `refind.conf` keeps a `.bak`.
- **Polish / English** interface following your system language, **PL | EN** switch.

### Download
**`ghoul-cyber-theme-studio-v1.0.0.zip`** — ready to run: app + theme engine + all themes.
- **Windows:** install [Python 3](https://www.python.org/downloads/) (tick *Add to PATH*), double-click `ThemeStudio.bat`.
- **Linux:** `./theme-studio.sh` (Python 3 + Tk).

Checksums: `sha256sum -c SHA256SUMS.txt`

### 🎭 Fan art
17 of the 18 themes are unofficial, non-commercial fan art inspired by popular anime and games — not affiliated with or endorsed by their creators or rights holders; all characters and trademarks belong to their owners. Rights holders can request removal through an issue.
