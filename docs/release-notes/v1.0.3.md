## Ghoul Cyber – Theme Studio v1.0.3

**🇬🇧 English** · [🇵🇱 Polski](#-polski)

- **Fix: installing rEFInd on a freshly installed Windows.** v1.0.2 could stop with `CERTIFICATE_VERIFY_FAILED` while downloading rEFInd: a new Windows has only a few root certificates and Python cannot fetch the missing ones. The download now tries Python, Windows' own `curl.exe` and PowerShell, for every mirror, and takes the first file whose SHA-256 matches the official rEFInd 0.14.2.
- Works behind company proxies (PowerShell uses the proxy set in Windows) and when a mirror answers with a web page instead of the file.
- Without internet nothing is changed, and the message says how to use a downloaded `refind-bin-0.14.2.zip` (`--refind-zip`).
- Engine updated to [`studio-engine-v1.0.3`](https://github.com/Dismonder/refind-theme-ghoul-cyber/tree/studio-engine-v1.0.3).

**Download:** `ghoul-cyber-theme-studio-v1.0.3.zip` — Windows: `ThemeStudio.bat` (Python 3), Linux: `./theme-studio.sh` (Python 3 + Tk). Checksums: `sha256sum -c SHA256SUMS.txt`.

🎭 17 of the 18 themes are unofficial, non-commercial fan art — not affiliated with or endorsed by the rights holders.

### 🇵🇱 Polski

- **Poprawka: instalacja rEFInd na świeżo zainstalowanym Windowsie.** W v1.0.2 pobieranie rEFInd mogło się zatrzymać z błędem `CERTIFICATE_VERIFY_FAILED`: nowy Windows ma tylko kilka certyfikatów głównych, a Python nie potrafi dociągnąć brakujących. Teraz program próbuje kolejno Pythona, wbudowanego w Windows `curl.exe` i PowerShella, dla każdego serwera lustrzanego, i bierze pierwszy plik, którego suma SHA-256 zgadza się z oficjalnym rEFInd 0.14.2.
- Działa za firmowym proxy (PowerShell korzysta z proxy ustawionego w Windows) i wtedy, gdy serwer lustrzany zamiast pliku odda stronę WWW.
- Bez internetu nic nie jest zmieniane, a komunikat podpowiada, jak użyć pobranego ręcznie `refind-bin-0.14.2.zip` (`--refind-zip`).
- Silnik zaktualizowany do [`studio-engine-v1.0.3`](https://github.com/Dismonder/refind-theme-ghoul-cyber/tree/studio-engine-v1.0.3).

**Pobieranie:** `ghoul-cyber-theme-studio-v1.0.3.zip` — Windows: `ThemeStudio.bat` (Python 3), Linux: `./theme-studio.sh` (Python 3 + Tk). Sumy kontrolne: `sha256sum -c SHA256SUMS.txt`.

🎭 17 z 18 motywów to nieoficjalny, niekomercyjny fan art — niepowiązany z właścicielami praw.
